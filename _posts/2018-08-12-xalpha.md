## Introduction

xalpha 是基金投资全流程管理的 Python 库：基金和股票信息与净值获取，精确到分的投资账户记录整合分析与可视化，简单的策略回测，以及根据预设策略的定时投资提醒。尤其适合资金反复进出的定投型和网格型投资的概览与管理分析。

主要功能：

- 一行拿到基金信息，一行根据交易账单对整个基金组合做全模拟，结果与实盘一致。
- 统一的日线和实时数据获取器，几乎任何市场上的产品都可以一行取得价格数据。
- 指数、行业、基金和个股的历史估值与即时估值分析。
- 可转债定价。
- 核心 QDII 基金的 T-1 净值预测，以及基于期货的 T-0 实时净值估算。
- 穿透基金组合的底层持仓，查看等效股票集中度和行业分布。
- [AI agent 原生支持](https://xalpha.readthedocs.io/en/latest/xalpha_agent/index.html)：用自然语言描述筛选条件或策略，由 agent 调用 xalpha 完成数据获取、筛选和回测。

```python
import xalpha as xa

xa.fundinfo("501018")                                 # 基金信息
shipan = xa.mul(status=xa.record(path))               # 按账单模拟整个组合
shipan.summary()
xa.get_daily("SH518880")                              # 历史日线
xa.get_rt("commodities/crude-oil")                    # 实时数据
xa.QDIIPredict("SH501018", positions=True).get_t0_rate()  # QDII 实时净值估算
```
